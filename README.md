# Rahil & Fiza — Wedding Invitation

A luxury digital wedding invitation website built with React 18, Vite, and Tailwind CSS. Customized in a Royal Bottle Green and Champagne Gold aesthetic.

## Features
- **Interactive Intro Video**: Envelope reveal animation ("Tap to Open")
- **Scratch-to-Reveal**: Interactive canvas Save-the-Date scratch card
- **Event Schedule & Google Maps**:
  - Haldi & Mehendi (Thursday, 24 December 2026)
  - The Nikah Ceremony (Saturday, 26 December 2026)
  - Reception (Walima) (Sunday, 27 December 2026)
- **Our Moments**: Milestones timeline
- **Audio Experience**: Embedded music playback (Kudmayi)
- **Mobile-First Luxury Design**: Elegant typography, floating ornamental masquerade masks, chandeliers, and smooth scroll animations

## How to Run Locally

### Option 1: Python HTTP Server (Recommended)
```bash
python -m http.server 8080
```
Then visit [http://localhost:8080](http://localhost:8080) in your browser.

### Option 2: Node.js Serve
```bash
npx serve .
```
